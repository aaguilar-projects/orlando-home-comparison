# Orlando home comparison

A static comparison of ten Orlando listings with editable financing, cash-to-close and monthly budget assumptions.

Household financial fields start at zero. Changes are stored in the visitor's browser local storage; there is no application backend or analytics. Listing facts and cost allowances require independent verification.

Listing photos are embedded and credited to their respective providers.

Interactive map: Leaflet 1.9.4 (BSD 2-Clause), OpenStreetMap tiles and attribution. Coordinates from the U.S. Census Geocoder, checked November 14, 2026; approximate address locations rather than surveyed parcels. Map tiles require internet.
